# KALON
App/Product that designs memorial headstones (product of Healing Partners LLC). (This memorial Designer was called Remember Them, But due to Trademark issues, the name was changed to KALON). 

## Run the Headstone Design Lab

```sh
docker compose -f docker/docker-compose.yml up --build
```

Open <http://localhost:8080>. For the layout, build steps and template rules, see [AGENTS.md](AGENTS.md).
