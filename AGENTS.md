# AGENTS.md

Guidance for AI coding agents working in this repository.

## What this is

KALON is a memorial headstone designer, a product of Healing Partners LLC. The repo holds the
Headstone Design Lab, a front-end prototype exported from a Claude Design artifact. It has no
backend, persistence or accounts. Uploaded photos stay in browser memory.

## Layout

```
app/          The runnable site: static files. Serve this folder.
  index.html     Generated by src/build.py. Do not edit by hand.
  support.js     Runtime: React 18 plus the design-canvas renderer. Minified. Do not edit.
  fonts/         Self-hosted web fonts (SIL OFL) and fonts.css.
src/          Source for app/index.html.
  build.py       Joins the fragments listed in manifest.json into app/index.html.
  manifest.json  Ordered template and script fragments, nested wrappers, component entries.
  template/      Page markup, one folder per screen: head, shell, intake, building, scene,
                 options, editor, refine, final.
  script/        App logic in one global scope: catalog, shared, content, stone, layout,
                 generate, scenes, component (the Component class and renderVals regions).
  components/    Build-time UI components. See src/components/README.md.
tests/        Node checks that load the app logic from src/.
docker/       Dockerfile (nginx:alpine serving app/), nginx.conf, docker-compose.yml.
docs/         Handoff notes from the prototype export.
knowledge/    Committed code graph: knowledge/code_graph.db.
.githooks/    Git hooks. Install once per clone: sh .githooks/install.sh
```

## Run

```sh
docker compose -f docker/docker-compose.yml up --build   # http://localhost:8080
```

Without Docker, serve `app/` over HTTP: `cd app && python3 -m http.server 8080`.
Opening `index.html` from disk (`file://`) is not supported.

## Build and test

Build needs `python3`. Tests need `node` and `python3`.

```sh
python3 src/build.py            # writes app/index.html
python3 src/build.py --check    # exits 1 if app/index.html differs from a fresh build
node tests/harness.js | tail -1 # must read: TOTAL red 124 yellow 365 edge 179
node tests/shapes.js            # every line must say red 0
```

The harness red count is a known baseline. A change that raises it is a regression.
`MISSING` lines for intake or building views are expected.

A change that only moves code between fragments or into a component must leave
`python3 src/build.py --check` passing without rebuilding. A behavior change rebuilds
`app/index.html`, which is committed.

## Editing rules

- Edit `src/`. Never edit `app/index.html` by hand.
- Fragments join byte for byte in manifest order. The script is one global scope with no modules.
- To reuse markup, add a component under `src/components/` and call it from the manifest or
  with an inline directive. Follow the argument convention in `src/components/README.md`.
- The renderer is strict:
  - `{{hole}}` holes are dotted lookups only (`{{l.x}}`). No expressions.
  - `<sc-for list="{{items}}" as="x">` needs an alias that is unique across the whole template.
  - `<sc-if value="{{flag}}">` handles conditionals.
  - Do not put whitespace inside text divs that use `white-space: pre`.

## Tooling

This repo expects the Library plugins from the `Alexk413x/marketplace` marketplace.
`.claude/settings.json` registers the marketplace and enables `codebase-kg`, `ide-agent-tabs`,
`sentinel-swarm` and `the-index`. Claude Code prompts to trust and install them on first open.

- Orient with the code graph before searching: `kg_search`, `kg_node`, `kg_neighborhood`.
  The graph says where code lives; the source says what it does.
- After changing mapped source, run `/codebase-kg:refresh` and commit the graph.
- `sh .githooks/install.sh` wires the pre-commit and pre-push staleness checks and the graph diff driver.
